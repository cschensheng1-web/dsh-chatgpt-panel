# 测试记录

版本 0.1.0-preview.6；2026-11-02。

## 自动化

- `npm run check`：构建生产客户端并执行 6 项单元测试。覆盖获批租约、隔离属性、初始化中关闭、挂载失败清理、安全弹出导航、可读错误、guest-ready 之后才允许刷新、真正调用 guest reload。
- `npm run test:ui`：用本地模拟的 Desktop bridge 加载实际生产包，验证内嵌默认视图、返回 DSH、关闭清理、再次进入，以及没有旧版入口、没有本地聊天 API 请求。此测试不访问官网。

开发 UI 检查需要 Google Chrome，插件运行不需要它。预览中的 Agent 是标识清楚的占位，不操作实际 DSH。

## 本机实测

使用官方 DSH Desktop 0.2.1-rc.5 / macOS arm64 的本地目录安装：

- 在 DSH 主面板中显示真实官网首页和输入框。
- 顶栏“返回 DSH 对话”回到原会话与原输入框。
- 再次进入 DeepSeek Chat，可重新看到官网页面。
- 检查时独立插件 Chrome 主进程为 0。

preview.6 本机复核：官网首页与输入框可见；“返回 DSH 对话”可回到原会话；再次进入可显示官网。没有“其他选项”或旧版入口。独立 Chrome 进程检查最初在 preview.5 完成，preview.6 已移除相关启动代码。移除操作没有删除用户原有本地文件。

## 尚未验证

用户账号在内嵌页面的实际登录、验证码、真实回答、GitHub 来源在不同网络下的安装，以及 Intel Mac、社区桌面版或其他 DSH 版本。当前 DSH 内嵌会话不跨应用重启保留；这不是插件可启用的选项。

复现：安装后打开 DeepSeek Chat，核对官网地址及页面，手动完成登录；发送一条无敏感内容的短消息。点击“返回 DSH 对话”核对原会话，再回到 Chat。不要向插件提供账号密码、Cookie 或令牌。
